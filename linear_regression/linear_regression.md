#### Complete implementation of Linear regression with numpy only 
Numpy lib is use for implementing the whole linear regression algorithms. Finding the bias and weight OLS method is implemented.<br>
beta = (X^T.X)^-1 . X^T . y <br>
The given equation helps to find the wegith and bias value for each columns. simple linear equatoin is use in linear algorithm to predict data i.e y_pred = beta1 * X + beta0(this is for single input features, if the number of features is increase then number of weight will in increase)<br>
